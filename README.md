# متجر شياكة وجمال وأناقة
ملفات الواجهة: index.html و styles.css و script.js ومجلد assets.

## الرفع إلى GitHub من الموبايل
1. افتح المستودع الذي أنشأته.
2. اضغط Add file ثم Upload files (أو افتح github.com/<اسمك>/shyaka-gamal-store/upload/main).
3. فك ضغط ملف ZIP على الهاتف أولًا، ثم ارفع الملفات والمجلدات الموجودة داخله، وليس ملف ZIP وحده.
4. اضغط Commit changes.

## ملاحظة مهمة
هذه واجهة متجر تجريبية تعمل في المتصفح. السلة والطلبات تحفظ محليًا على نفس الجهاز فقط؛ لا يوجد حتى الآن خادم أو قاعدة بيانات مركزية، لذلك لا تعتمد عليها لاستقبال طلبات عملاء حقيقية قبل ربط Backend وقاعدة بيانات ولوحة إدارة. الأسعار المعروضة تجريبية ويجب تعديلها.
